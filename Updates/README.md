# Выпуск обновлений

Пользователь нажимает ❄️ → «Проверить обновления…». Sparkle читает
`appcast.xml` из последнего GitHub Release, проверяет подпись архива и
предлагает установку с перезапуском. Коммит в main сам по себе не выпускает обновление.

## Один раз на Mac владельца

```sh
sparkle=$(zsh scripts/fetch-sparkle.sh)
"$sparkle/bin/generate_keys"
```

Скопируй выведенный **публичный** ключ (значение SUPublicEDKey) одной строкой
в `Updates/public-key.txt` и закоммить этот файл. Закрытый ключ остаётся
в Keychain; не отправляй его в GitHub или чат и не создавай новый при каждом выпуске.
До настройки ключа кнопка показывает понятное сообщение; проверки сети не запускаются.

Первую сборку с ключом нужно установить вручную. Последующие сборки должны
использовать тот же ключ и тот же bundle identifier.

## Каждый выпуск

1. Увеличь `CFBundleVersion` (целое число) и `CFBundleShortVersionString`
   (например, 0.2.1) в `Info.plist`. Закоммить изменения.
2. На Mac, где сохранён ключ, выполни `zsh scripts/prepare-update.sh`.
3. Проверь архив и обновление на тестовой копии установленного приложения.
4. Создай GitHub Release с тегом той же версии, например `v0.2.1`,
   и прикрепи **оба файла** из `dist/v0.2.1`: ZIP и `appcast.xml`.
   Опубликуй как обычный Latest release, не prerelease.

Не заменяй уже опубликованный ZIP: выпусти новую версию.
Номер сборки должен всегда увеличиваться. Все обычные Latest releases
должны содержать appcast.xml, иначе кнопка не сможет проверить обновления.

Сборка universal поддерживает Intel и Apple Silicon. Без
`CODE_SIGN_IDENTITY` создаётся локальная ad-hoc сборка с исключением
Library Validation, необходимым Sparkle. Для публичного распространения
используй Developer ID (переменная `CODE_SIGN_IDENTITY`), notarization
и stapling до упаковки. Ключ Sparkle не заменяет подпись Apple.
Скрипт подготовки сейчас предназначен для локальных выпусков;
notarization он не выполняет.

## Проверка перед первым выпуском

- `zsh build.sh`: universal-сборка, проверка подписи и self-test.
- Запуск из «Программ», кнопка на русском и английском, отказ сети.
- На отдельной тестовой копии: обновление с меньшего номера на больший,
  перезапуск и сохранение настроек.
- Архив с неверной подписью должен отклоняться; повторная проверка во время
  текущей проверки должна быть недоступна.
